# Python

Python was created by Dutch programmer **Guido van Rossum in 1991**
The language's name was inspired by the British comedy group,
Monty Python's Flying Circus.

Creator : **Guido van Rossum**
Origin : **Netherlands**
Start date :**Began in 1989**
First release : **February 1991**
Motivation : **He wanted to create a programming language that was readable and improved developer productivity**.
