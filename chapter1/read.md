# module

A module is a file containing Python code, which can include definitions of functions, classes, and variables. Essentially, any Python file saved with the .py extension can be considered a module.

# pip

PIP (officially known as "Preferred Installer Program" or recursively as "Pip Installs Packages") is the standard package manager for Python. It is a command-line tool used to install, manage, and uninstall Python packages and their dependencies.

# Two types of modules

1. **Built-in Modules**: These modules are part of the Python Standard Library and come pre-installed with Python. They provide functionality for common tasks and are readily available for use without any additional installation. Many built-in modules are written in C for performance optimization.

2. **User-defined Modules**: These are custom modules created by developers to organize and reuse their own code. A user-defined module is essentially a Python file (.py extension) containing functions, classes, variables, or other Python code that can be imported and used in other Python scripts or programs.

# Using Python's Interactive Interpreter (REPL):

The simplest way to use Python as a calculator is through its interactive interpreter, often called the REPL (Read-Evaluate-Print Loop). You can access it by typing python or python3 in your terminal or command prompt.
Once in the REPL (indicated by >>>), you can directly type expressions and press Enter to see the result
